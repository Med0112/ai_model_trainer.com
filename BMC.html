الشركاء الرئيسيون

Key Partners

  • الجامعات الجزائرية — قاصدي مرباح ورقلة، هواري بومدين، وغيرها للاستخدام الأكاديمي
  • وزارة التعليم العالي — دعم رقمنة التعليم واعتماد المنصة في المؤسسات
  • مزودو الحوسبة السحابية — AWS، Google Cloud، Algérie Cloud (تخزين وتدريب سحابي)
  • مجتمع المصادر المفتوحة — مطورو YOLO، OpenCV، Hugging Face
  • شركات التقنية الجزائرية — تكامل محلي ودعم فني
  • الحاضنات الجامعية — دعم ريادة الأعمال والتسويق

الأنشطة الرئيسية

Key Activities

  • تطوير المنصة — منصة ويب، تطبيق ديسكتوب (Electron)، تطبيق هاتف (Kotlin)
  • تدريب وتحسين النماذج — YOLOv8+، نماذج رؤية حاسوبية مخصصة
  • إدارة البيانات — جمع، تنظيف، وسم (يدوي/تلقائي)
  • دعم العملاء — دعم فني، تدريب، وثائق تعليمية
  • تسويق وشراكات — عروض للجامعات والشركات
  • تطوير المجتمع — منتدى مطورين، محتوى تعليمي

القيمة المقدمة

Value Proposition

  • 🎯 تدريب بسيط — بدون خبرة برمجية، واجهة سهلة خطوة بخطوة
  • 🌐 3 منصات متكاملة — ويب + ديسكتوب + هاتف في نظام واحد
  • 📴 تدريب محلي بدون إنترنت — عبر تطبيق الديسكتوب (CPU/GPU)
  • 📱 تشغيل فوري على الهاتف — التعرف عبر الكاميرا (Live Detection)
  • 🏷️ وسم تلقائي ويدوي — تسريع عملية إعداد البيانات
  • 📚 مكتبة نماذج جاهزة — تحميل واستخدام فوري
  • 👥 مجتمع مطورين — مشاركة النماذج والخبرات
